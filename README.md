# Cac_Bolsa

Este é um **aplicativo financeiro** voltado para análise e auxílio na gestão de finanças e obrigações fiscais. Ele possui quatro módulos principais:

1. **📊 Cálculo de M2 (Agregado Monetário)**  
   Calcula a **variação percentual do M2** entre dois períodos (geralmente meses), com base nos valores informados.  

2. **💰 Investimentos**  
   Permite simular o crescimento de um investimento ao longo do tempo, considerando juros compostos, prazos e taxas de rendimento.

3. **📄 Ajuda com Declaração**  
   Dá orientações básicas sobre como organizar e classificar seus rendimentos e bens para preparar a declaração do imposto de renda.

4. **💱 Câmbio**  
   Faz conversão de moedas com base nas cotações atualizadas, como dólar, euro, libra, etc.
